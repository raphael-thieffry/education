# TP2 : Développement piloté par les tests (TDD)

Bienvenue dans le TP2 de développement piloté par les tests. Suivez les consignes du document fourni pour travailler en équipe de manière collaborative. Ce projet est conçu pour vous aider à acquérir des compétences en TDD, en passant par la spécification, la création de tests, et le développement d’une implémentation minimale.

## Instructions pour démarrer

1. **Mise à jour du README** : Avant de commencer le TP, chaque équipe doit compléter le README en ajoutant les noms des membres des deux sous-équipes.
   - **Équipe DEV** : responsable de la rédaction de la spécification et du développement de la classe.
   - **Équipe TEST** : responsable de la rédaction et de l’exécution des tests.

2. **Suivre les consignes** : Consultez attentivement le PDF fourni pour les instructions détaillées. Respectez les étapes, notamment l’échange des spécifications avec une autre équipe, afin de valider et d’améliorer votre travail collaboratif.
