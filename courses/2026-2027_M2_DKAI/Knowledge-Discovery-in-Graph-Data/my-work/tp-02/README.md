# Knowledge Discovery in Graph Data — TP1 (S02)

1. Extract the entire archive and keep its folder structure.
2. Open `student/tp-02.ipynb` in JupyterLab or VS Code and select a Python 3.11 or newer kernel.
3. Run the cells in order. Complete the projection exercise in section 1 before running that cell. Pause at each prediction prompt before inspecting the AMIE output.

The notebook uses Python's standard library and reads the included AMIE runs by default. This mode works offline once Jupyter is set up.

## Run AMIE locally (optional)

With Java installed, download [AMIE 4.0.0](https://github.com/dig-team/AMIE/releases/download/v4.0.0/amie4.0.0.jar) from the official release and save it as `tools/amie4.0.0.jar` relative to this README. Create the `tools/` directory if needed. In the notebook, set `RUN_NEW = True` and rerun the AMIE cells.
