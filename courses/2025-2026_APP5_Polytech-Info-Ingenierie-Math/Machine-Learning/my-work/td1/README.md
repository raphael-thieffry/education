# TD1 – Frequent Itemset Mining

Bienvenue dans le dépôt du **TD1 : Frequent Itemset Mining**.

Ce dépôt est fourni via **GitHub Classroom** et constitue le support de travail individuel pour ce premier travail dirigé.  
Chaque étudiant doit **personnaliser et compléter** ce dépôt avant de rendre son travail.

---

## 🎯 Objectifs du TD

Ce TD a pour objectifs de :

- Comprendre les concepts fondamentaux du **Frequent Itemset Mining**
- Manipuler les notions de **support**, **fréquence absolue** et **fréquence relative**
- Appliquer les propriétés d’**anti-monotonie** et **Apriori**
- Implémenter et comparer des algorithmes d’extraction d’itemsets fréquents
- Se familiariser avec l’utilisation de **GitHub Classroom**
